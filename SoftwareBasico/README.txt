QUESTIONARIO - TRABALHO FINAL

Programa em C para praticar questoes de multipla escolha.
Sorteia uma questao por modulo e reaplica as erradas ate acertar todas.

Como compilar e executar

1. No Linux ou Ubuntu pelo WSL, abra o terminal na pasta do projeto.
   E necessario ter o GCC e o make instalados.
2. Para compilar, execute:
   make
3. Para iniciar o programa, execute:
   ./questionario

Mantenha os arquivos de questoes .txt na mesma pasta dos arquivos do projeto
e execute o programa a partir dessa pasta.

Como usar

Informe um identificador sem espacos e responda com A, B, C ou D.
Letras minusculas tambem sao aceitas. As questoes e alternativas sao
embaralhadas, e as questoes erradas voltam nas rodadas seguintes.

Ao terminar, o programa mostra a pontuacao e as estatisticas do usuario.
A data e a pontuacao sao acrescentadas ao arquivo identificador.txt,
criado automaticamente na pasta do projeto. Use o mesmo identificador
nas proximas sessoes para manter seu historico.
